# AI 编辑器与写作 Chat 回归

当前文字入口统一为写作对话，`browser.py` 转交 `chat_browser.py` 验证聊天界面；配图组件保持原样。下文“第二批”至“第四批”为兼容接口与既有测试的开发记录，涉及旧按钮界面的描述以本节为准。

- 文字请求使用 `/blog/ai/chat` 的 `action: conversation`，模型一次调用理解需求并返回结构化的建议、选区修改、新正文、大纲、标题、摘要或标签。流式输出只呈现可读正文，完整结束且格式校验成功后才允许采纳；没有有效选区的修改结果不得替换正文。
- 同一对话可继续追问，“引用”可明确选择较早一版作为上下文。最近六条历史参与模型请求，单条最多8000个 Unicode 字符，后端历史总预算16000字；完整本地记录与模型上下文分开。
- 使用 `localStorage`，键包含用户身份与文章标识。每篇最多5个会话、每会话40条消息；单篇序列化上限500000字符，功能总预算1000000字符（约2 MB UTF-16文本）。超出时优先淘汰旧会话和旧消息；不能保存时明确提示，当前页面结果仍可复制。未知用户或无编辑器时只使用页面内存。
- 流式增量留在内存；请求开始、完整结束、停止、采纳及会话切换时保存。未发送输入延迟400ms保存。刷新恢复记录，将未完成请求标记为停止；不自动重发。清空需确认，不改变文章。会话下拉列表支持逐条删除并确认，删除当前会话自动切换，删除最后一条后创建空白会话；删除不会改动正文或其他文章的聊天记录。
- 原选区、原插入位置、正文、标题及摘要随结果保存。恢复时只在文章和正文完全相同时重新绑定编辑器实例；正文变化则禁止采用旧结果。标题和摘要另检查人工编辑冲突。插入和追加接入原有AI撤销历史。
- 修改对比采用即时决策：点击采用即替换这一处，点击保留原文则直接结束这一处；未处理部分始终保留原文，处理后只展示选定内容，全部处理完自动退出，不再需要全局应用。批量按钮只处理剩余修改；“结束对比”保留已经采用的内容和未处理原文。每次实际替换更新快照范围，并产生可逐步撤销的记录。
- 多标签页用本地版本及 `storage` 事件检测更新，发现冲突时停止覆盖并提供载入入口。切换文章或用户取消生成并恢复各自记录，关闭抽屉保留对话。聊天记录不跨设备同步，不持久化令牌或模型密钥。
- 浏览器覆盖多轮追问、刷新和输入恢复、选区对比、固定光标插入、撤销、元数据回填、停止与失败、文章及会话隔离、真实抽屉入口、章节写作、图示导出和图片采用、Markdown安全以及模型管理。AI接口均使用模拟响应，不验证真实供应商的意图理解质量。

在 `web` 目录执行 `npm run test:ai`，验证无损 diff、选区快照、撤销和 Store 接线。

浏览器测试使用 Python Playwright 和本机 Chrome（可通过 `--channel msedge` 使用 Edge）：

```sh
python -m pip install playwright
npm run test:ai:serve
# 在另一个终端执行：
python tests/ai-editor/browser.py
python tests/ai-editor/paragraph_browser.py
python tests/ai-editor/diff_context_browser.py
```

长内容滚动回归使用 Node Playwright（需可解析 `playwright` 模块）：`node tests/ai-editor/scroll_browser.cjs --channel msedge`。
覆盖真实 AI 抽屉在桌面、矮窗口、手机和横屏尺寸下的长图示、竖向配图、上传操作、长聊天回复、二十章大纲和章节预览，确认滚轮可以到达底部按钮；所有 AI 和上传接口使用模拟数据。

独立 Vite 夹具使用真实 MarkdownEditor、WritingAssistantPanel 和 Pinia Store，所有 AI 接口均由测试拦截，不需要登录或模型密钥。默认端口为 5191；可通过 `AI_TEST_PORT` 和测试的 `--base-url` 调整。

覆盖：局部与全文替换、全文预览、精确撤销、CRLF/emoji、逐段采纳、全部保留、取消、编辑冲突、切换文章、残缺流，以及三处 HTML 渲染的清洗和正常 Markdown 保留。

第二批增加：SSE 跨分片 CRLF/UTF-8、多行 data、业务错误与完成事件校验；摘要/标签取消后立即重试、旧请求隔离、错误结果禁止回填；文章切换清理历史；模型管理 ID 对接。

后端包含本地模拟供应商的 API 流式完成原因测试（正常结束、输出截断、缺少完成原因），不会调用外部模型。

后端在 `server` 目录运行 `go test ./service/blog ./service/ai ./api/v1/blog ./api/v1/ai`。
配额集成用例需要专用临时 Redis：设置 `AI_TEST_REDIS_ADDR=127.0.0.1:16391` 后运行相同命令并加 `-count=1`；未设置时该集成用例跳过。测试使用 DB 15 的专用用户键，不能指向业务 Redis。

配额约定：按服务器本地日期计算，次日零点过期；状态查询不计次，参数校验失败或无可用配置不计次；通过校验且配置可用的生成请求计一次，模型失败或用户取消不退回。启用限额时 Redis 不可用会拒绝生成并提示。

文章隔离约定：切换文档、编辑器或离开编辑页面时取消生成，写作 Chat 按用户和文章保存、恢复本地会话。章节未采纳草稿和配图预览仍按原流程清理；关闭 AI 抽屉保留当前文章状态。

第三批增加：

- 摘要和标签的正文预算使用 `ai.context-limit`（默认 8000 个 Unicode 字符），短文全部读取，长文选取均匀分布的最多五个窗口，并返回取材范围提示。仍为一次模型调用；这不是分段阅读全文后汇总，不能保证覆盖所有细节。正文预算不包含系统提示、目录和工具结果，也不等同于 token 上限。
- 润色、改写、自定义指令的选区超过正文预算时拒绝请求，不静默截断；自定义指令优先处理完整选区，剩余预算提供文章背景。
- 续写按 UTF-16 光标位置读取前文，文首光标不再回退到文末；对话历史最多六条，每条最多 1000 字。
- 推荐结果严格校验 JSON、归一化名称并返回已有项 ID；已有标签最多三个、新标签最多两个。未知分类被忽略，未知标签仅作为可选新标签。
- 回填追加所选标签并保留已有项；新标签默认不选，勾选后以待新建名称进入表单，保存文章时创建。不存在的已有项和不匹配的 ID 不允许回填。

第三批命令 `npm run test:ai` 增加表单回填和光标测试；Go 用例增加长文取材、选区预算、推荐校验，以及本地模拟供应商的摘要请求测试。`browser.py` 包含新标签勾选、取材范围提示和光标传参测试，需要安装 Python Playwright 才能执行。

第四批增加：

- 标题候选以最多五条纯文本展示，可逐项回填；支持只有标题/主题时重新起标题。生成后人工修改了标题时拒绝覆盖。
- 正文生成偏好支持自然、正式、亲切、技术表达、克制客观五种语气，以及保持篇幅、精简、扩写。润色、改写、自定义指令另支持轻度修饰、常规优化、充分改写三档修改力度；默认常规优化，旧请求不传仍兼容。篇幅比例不用于续写，续写仍限制为 300 字；章节使用独立字数范围。后端验证所有枚举；大纲、标题、摘要、标签不受这些偏好影响。作者明确指令优先，但润色与改写仍保持段落数量与顺序。这些是提示词要求，不保证模型精确遵守比例。
- Mermaid 围栏代码在编辑器正常预览、AI 对比预览、助手结果、章节草稿，以及博客正文和文档阅读页中按需渲染。Markdown 原文保持不变；图示以隔离的 SVG 图片显示，支持查看源码，错误时保留代码。每个预览最多12张图，单图源码最多20000字符、最多200条边；不接受图内配置指令和配置前言。前后端包内各保留一份相同渲染器，以兼容独立 Docker 构建；修改渲染器需同步两个副本。
- 成功、失败和取消后均可重新生成，沿用上次输入、选区、偏好和生成前的历史；正文、标题或编辑器变化时拒绝重放旧任务。重试属于新的生成请求，按第二批规则再次计次；不会自动重试。
- 自定义选区结果先展示，再由作者点击「与原选区对比」进入已有 diff；仍使用请求发出时的选区快照，支持内联/分栏与逐块采纳。
- 相关纯逻辑覆盖位于 `writingTask.test.js` 和 `ai_preferences_test.go`；浏览器脚本增加标题保护、偏好传参、重试历史和自定义对比流程，需要安装 Python Playwright 后执行。


写作 Chat 后续回归增加：快捷操作合并未发送要求、部分采用后继续修改实际正文、明确旧回复引用、审阅精确定位与单段修改（重复原文拒绝定位），以及真实抽屉内分片流式输出时暂停跟随和返回最新回复。`followup.test.js` 覆盖相关范围、历史与结果校验；浏览器继续覆盖原配图生成、采用、上传和撤销流程，全部模型请求使用模拟数据。


快捷提示词统一维护在 `writingPrompts.js`，选区浮动入口复用同一套润色与改写指令。标题、摘要、标签、审阅、大纲在自动范围且没有补充要求或引用回复时默认参考全文；明确的选区范围、自定义补充与回复引用保持原有目标。后端向模型明确传递是否有正文、是否有选区及参考是否抽样，防止把写作要求当成文章、将抽样误认为全文。浏览器测试验证参考范围和补充要求传参，Go 测试验证材料标识；生成质量仍需实际模型评估。


图示回归增加：自动流程图的节点、连线、标签安全上限及阶段分组校验（Go）；渲染尺寸、字号与布局选择（Node），结构图不受自动流程图限制；长 Mermaid 图的420px预览上限、完整查看与缩放、Esc关闭、正文变更时弹窗清理（浏览器）。后台与博客前台保持相同渲染器和样式；预览高度不影响矢量到PNG的高清导出。

段落编号回归：`paragraph-index.test.js` 验证 Markdown 原子块、CRLF/Unicode 偏移、重复段落、中文数字、连续范围及无效编号保护；`paragraph_browser.py` 验证真实编辑器编号、点击选择、按编号请求、即时采用与撤销，以及软换行、缩放和实际滚动对齐。模型响应使用模拟结果，不验证供应商的真实生成质量。

完整正文对比回归：`diff_context_browser.py` 验证选区前后及选区内部未修改内容持续展示，内联/分栏切换、多处即时采用/保留、CRLF 与 emoji 无损撤销，以及文首/文末/全文/句中选区、长文定位和正文冲突保护。上下文仅参与展示，不改变原有修改块索引或写回范围。
